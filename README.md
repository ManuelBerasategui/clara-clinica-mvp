# Clara · clínica dental (prototipo)

Prototipo estático para revisar y editar la experiencia de una clínica dental. Está hecho en un solo `index.html` y no requiere dependencias.

## Publicar o previsualizar

Abrí `index.html` en el navegador o publicá la carpeta raíz con GitHub Pages. Los datos de ejemplo son ficticios. El sitio no guarda cambios ni se conecta a WhatsApp, ARCA, financiadores ni a una base de datos.

## Cómo colaborar

1. Editá `index.html` desde GitHub (botón Edit) o cloná el repositorio y abrilo en un editor.
2. Para compartir cambios, creá una rama y un Pull Request.
3. GitHub Pages vuelve a publicar los cambios al actualizar la rama y carpeta configuradas.

No agregues datos reales de pacientes, claves, certificados ni credenciales al repositorio.
